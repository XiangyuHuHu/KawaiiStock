## 0. 先看结论：策略的完整逻辑

**发现市场正在奖励的行业 → 找到相对强势且成交活跃的股票 → 将扫描结果放入观察名单 → 等突破后的第一次回调或关键位置反转 → 用更小周期确认入场 → 入场前定义失效位和仓位 → 小亏快退、允许重新尝试 → 在加速行情部分止盈，用均线跟踪其余大趋势。**【M1】【M2】【I1】

- 核心优势：用严格定义的小额风险，争取少数大的盈利交易；不需要每次都预测正确。【M1】
- 核心代价：可能低胜率、频繁止损、多次重入；在横盘/剧烈震荡中容易被洗掉。Martin 披露 2024 年胜率约 25%，曾出现连续 18 笔亏损和约 30% 回撤。【M1】
- **不同于“股价低于21EMA立即卖”**：9/21/50 EMA 用于观察趋势和入场；**他2025年在评论区明确说过以9或23 EMA跟踪止盈**，有时部分止盈，每次约10%；这不等于每次触线就无条件全仓卖出。【M2】
- 不是完整闭源交易系统源代码：公开资料仍未明确所有触发细节、盘中执行协议和最终参数，因此**不能承诺100%复刻其真实成交**。

## 2. 第一层：市场状态 / Market Regime

### Martin 公开强调的原则【M】

1. 主动识别**新出现的热门主题**：不是只看单个股票上涨，而是观察同一领域多只股票同时进入扫描器，或观察名单从弱势升级为强势。【M1】
2. 大盘结构变差、突破接连失败、个股跌破关键EMA，是降低交易质量预期的重要信号。【M3】
3. 没有好机会可以不交易；他曾反省在差行情里报复交易和反复试错造成的大幅回撤。【M1】【I1】

### App可落地的过滤器【A：待回测】

- `RISK_ON`：SPY/QQQ 指数价格及关键均线向上、突破成功率改善、市场宽度增加；允许正常新开交易仓。
- `NEUTRAL`：指数分化或震荡；只做极清晰的首次回踩，单笔风险减半。
- `RISK_OFF`：宽度变差、指数跌破多条均线、突破持续失败；不主动寻找大量新多单，优先现仓保护。
- 推荐将行业广度、同板块新高数量、失败突破比例、相对强度纳入统一判断；**阈值需要由历史样本校准**。

**注意：** 他个人偏好熟悉的高波动科技股，并不意味着你的 App 应只扫描科技。你原有的全行业无偏机会扫描应独立保留。

## 3. 第二层：Martin 三套公开扫描器（2025-02-02 原始参数）【M2】

### 3.1 Potent Scan：前一日强势/活跃股

| 字段（原始写法） | Martin 公开条件 | App实现提示 |
|---|---|---|
| `Market cap` | `> 100M` | 总市值 > 1亿美元 |
| `Volatility 1W` | `> 3.5%` | **平台“1W波动率”指标**，别擅自改写为ADR20或1周涨幅；需匹配原扫描平台定义 |
| `Price` | `> 21EMA` | 股价在21日EMA之上（确认是日线口径） |
| `Vol × Price` | `> 50M` | 按平台的成交量×价格字段筛选，避免与10日平均美元量混同 |

用途：发现已经表现活跃、仍有技术强度的个股，**加入观察名单而非马上买入**。推荐按涨幅、相对强度和量价排序；排序是工程改造，原始截图并未明确所有排序细节。

### 3.2 Premarket Scan：盘前异动

| `Pre-market Chg %` | 按盘前涨幅**降序**排序 |

用途：关注可能因财报、指引、新闻或主题催化发生跳空的股票。盘前异动**只是线索**，要核验信息、成交深度及开盘后的回调形态，不能机械追最高涨幅。【M2】【A】

### 3.3 Leader Scan：近一个月领涨股（截图外，本人确实公开）

| 字段 | Martin 公开条件 |
|---|---|
| `Market cap` | `> 100M` |
| `Avg volume 10D` | `> 500K` 股 |
| `Vol × Price 1W` | `> 300M` |

他在2025年提到每天大约用30分钟查看 Potent 与盘前榜单，周末研究近30天领涨股。【M1】【M2】

**工程提醒：** `Vol×Price`、`Vol×Price 1W`、`Volatility 1W` 是原扫描器字段名，可能与数据供应商的计算口径不同。开发时必须保留 `source_field` 与 `normalized_field` 两个字段，并验证原平台单位；不能把50M/300M直接当成普适的平均日成交额阈值。

### 3.4 五类观察名单【M1】

- 当天主观察名单：当天最有可执行性的股票。
- 小盘观察名单：市值小于50亿美元。
- `Lead`：`EMA9 > EMA21 > EMA50`。
- `Mediocre`：原文举例包括 `EMA9 > EMA21 < EMA50`，或 `EMA9 < EMA21 > EMA50`（均线交错过渡态）。
- `Lag`：`EMA9 < EMA21 < EMA50`。

**重要：** EMA排列是**股票池强度分类**，不是单独的买卖按钮。股价跌破9 EMA、但21/50EMA仍稳步上升，与三条均线齐跌，是不同交易状态。

## 4. 第三层：指标怎样算，怎样看

### 4.1 EMA 指数均线

`EMA_t = alpha × Close_t + (1-alpha) × EMA_(t-1)`，其中 `alpha = 2/(N+1)`。

- `EMA9`：短线动量与紧跟踪线；对加速段更敏感。
- `EMA21`：回踩与中短期上升趋势结构。
- `EMA50`：中期趋势/反转过滤。
- `EMA23`：**Martin本人2025年提到用于移动止盈的候选均线**；不能直接替换为21而称为他的精确止盈规则。【M2】
- 额外研究：周线9/21EMA、200日MA；这些可帮助你的中期核心仓过滤噪声，但不是他的每笔交易统一硬标准。【A】【I1】

**错误示例：** “收盘价跌破9EMA，所以卖出全部VST/MU”。更合理的判断是价格结构、仓位属性、放量程度、21/50EMA是否同时失守、宏观板块是否共振。

### 4.2 ADR / ATR：不要混为一谈

- `ADR20%`：可研究采用 `mean((High-Low)/Low × 100%, 最近20个交易日)`；如原平台采用不同分母或仅计算美元区间，需明确转换定义。TradingView ADR 指标也可用作交叉核对。
- `ATR14`：包括隔夜跳空的真实波幅 `TR=max(H-L,abs(H-prevClose),abs(L-prevClose))`，再取14日平滑/平均，需固定采用哪种算法。
- Martin 2024 年偏爱 `ADR>5%` 的高波动股票，但说过**不是硬门槛**。【M1】
- 若某股 `ADR=5%`，Martin本人当时的经验性止损通常力求小于其一半（约2.5%），但若开仓结构不允许合理设置紧止损，应**放弃交易而非强塞一个容易扫损的价格**。【M1】【A】

### 4.3 AVWAP 锚定成交量加权均价

`AVWAP_t = sum(典型价格_i×成交量_i, i从锚点到t)/sum(成交量_i, i从锚点到t)`。

- 锚点候选：重要摆动高点/低点、明显突破日、财报跳空日、阶段行情起点；**实际锚点选择必须在当时信息可知的条件下完成**。【I1】【I2】【A】
- AVWAP与EMA、水平支撑重叠形成“共振区”；只把它看成候选支撑，仍需等待反转确认，不是假定机构一定会护盘。
- 日线AVWAP识别区域；5/15分钟图决定触发价；如果没盘中数据，不能假装已观察到V型反转。

### 4.4 R倍数 / 风险收益比

- 多头 `R_per_share = entry_price - initial_stop`；`profit_R = (exit-entry)/R_per_share`。
- 例如入场$100、初始止损$97，则每股风险$3；卖在$109约为+3R（不考虑费用/滑点）。
- **R必须由交易前记录的初始止损计算**，不得事后倒推最漂亮的R。

## 5. 第四层：三种多头交易形态

### L1. Breakout：整理平台突破【M3】【I1】

1. 上层：近期领导行业 + 高相对强度，日线整理区逐步收紧。
2. 重要价位：平台高点、前一日高点、开盘区间高点（ORH）。Martin的研究提到，他常用ORH或前一日高点做突破入场。【M3】
3. 入场：价格突破明确阻力并获成交量/走势确认；如突破时远离支撑，**可以选择不追**。【A】
4. 初始止损：突破结构失败位、回踩低点或开盘区间低点，先算距离再决定股数。【A】
5. 典型失败：突破后迅速回到平台内，尤其板块其余领头股同步走弱。

### L2. First Pullback：首次回踩反转【I1】【I2】

这是2026年公开访谈着重讨论的方向：**上升结构中的首次回踩**，而不是下跌股票抄底。

1. 用月度Leader/近3–6个月强势股建立候选；检查较长周期上升结构和整理基础。
2. 标出上升的9/21EMA、重要AVWAP与突破缺口、前高变支撑等共振区。
3. **价格回到支撑区域但没有持续崩跌**，在5/15分钟内出现快速收复、V形反转、强K或重新站上VWAP。
4. 进场价选在反转K高点突破或已确认的重新站稳价附近（工程化候选）。
5. 初始止损放在反转低点/支撑失效点；若距离太大则拒绝，不为了凑仓位而扩大风险。
6. 一个观察名单信号不能当成已确认买入信号；`SCANNED -> WATCH -> SETUP -> TRIGGERED -> FILLED` 逐级处理。

**潜在风险：** 价格只是在下降趋势中反弹，9/21/50EMA斜率都向下，则不属于“强势股回调”，容易把抄底误判成Martin风格。

### L3. Episodic Pivot（EP，事件拐点）/ 财报后异动【M3相关】【A】

Martin受Qullamaggie体系影响，也提到EP研究，但可查公开资料**没有给出一套完整且固定的Martin版EP数值参数**。这里仅记录工程框架：

- 事件必须能核实：财报、订单、指导性预测、重磅审批、监管/诉讼变化。
- 先记录盘前跳空、盘前量与流动性，再看常规时段开盘区间是否站稳。
- 将EP策略单列研究，与 L1/L2 分开回测，不把第三方所述“固定首小时/固定涨幅”冒充他的本人规则。

## 6. 第五层：入场止损（最值得认真执行的部分）

### 6.1 Martin本人2024年明确分享的经验【M1】

- **先决定失败位置，再买入**；成交后尽快放入保护性止损单。
- 当时常见止损幅度约 **1%–5%**，2024年超过80%的交易止损距离 **<3.5%**。
- 通常希望止损距离不要超过个股ADR的一半。
- 每笔初始**账户风险**约 `0.5%–1%`，这是止损发生时的理论资本损失比例，不是持仓占总资产的比例。
- 可以被止损后重新进入，只要交易机会和市场条件仍有效；但多次重入会带来过度交易风险。

### 6.2 2026年进一步公开信息【M3】【I1】

- 在其做空研究中，他提到单笔账户风险约 **0.5%**，做空交易通常避免单笔占账户超过 **35%**（这是其当时短空风控描述，**不是适用于所有交易的统一上限**）。
- 交易结构不理想时缩小规模；大盘/策略未见起色时也应降低账户风险。
- 任何高波动股票即使设置止损，也可能跳空跳过止损价，实际亏损并不封顶。

### 6.3 计算公式（可直接用于App）【A】

```text
account_risk_usd = verified_equity * allowed_risk_pct
stop_distance     = entry_price - planned_stop_price
risk_based_shares = floor(account_risk_usd / stop_distance)
capital_shares    = floor(available_buying_power / entry_price)
weight_cap_shares = floor((max_symbol_weight * verified_equity - existing_symbol_market_value) / entry_price)
new_shares        = max(0, min(risk_based_shares, capital_shares, weight_cap_shares))
```

示例：账户净值$300,000、单笔风险预算0.5%=$1,500；入场$100、止损$97（每股风险$3），风险预算理论上最多500股、名义仓位$50,000；**如单票权重上限10%，应将该笔限制为最多300股**，且还要检查总行业敞口、现金、已持仓、期权占用和佣金。

**止损单限制：** 普通止损市价单可能在跳空行情滑点成交；止损限价单可能无法成交；盘后/盘前触发方式依券商而异。不能把硬止损理解为“最大只亏0.5%”。

### 6.4 适配你主账户（与Martin原规则区分）【A】

- **新建的Martin风格短线交易仓**：用结构止损 + 仓位计算，试验起始风险预算可设 `0.25%–0.5% NAV/笔`，先模拟/回测。
- **已经持有较久的核心/成长仓**：不把历史买入成本重新伪装成今天的“1%新开仓止损”；按已占仓位、21/50EMA、周线、ATR、基本面失效和相关性综合管理。
- **板块风险联合计算**：例如数据中心、AI电力、算力链股票不能因为名称不同，就各自重复使用满额风险预算。
- **再入场**必须是新信号、新风险预算，不把连续补仓当成“重新入场”。

## 7. 第六层：止盈系统——本人原话及正确解读

### 7.1 强势中先分批止盈【M2】

Martin 在2025-02-06的本人回复中说明：

- 以 **9 EMA 或 23 EMA** 作为跟踪止盈参考。
- 在强势上涨中通常**每次卖约10%**。
- **第一笔部分止盈**的一个经验观察是上涨超过约 `3×ADR`。
- 他明确表示仍在探索较好规则，而且**随行情环境调整**。

**如何理解 `3×ADR`：** 如果ADR为5%，把 `3×ADR ≈ 15%` 作为一段上涨后的超额扩张量级来识别“可能值得第一次部分止盈”，是一个便于研究的近似方法。【A】 但他的原文没有严格规定“从成本算、从突破价算、用几天窗口算、是否必须15%”——**不能把 `profit_pct >= 3*ADR%` 写成毫无条件的Martin原始硬编码**。

### 7.2 余仓跟踪而非固定目标价清仓【M2】【I1】

- 股价延续强势、周线结构健康、上涨主题没有变，就让部分趋势仓继续跑。
- 对动量短线仓研究：`close < EMA9` 作为较快退出信号；另设 `close < EMA23` 作为较慢宽松版本进行独立回测。
- 对中期核心仓研究：`EMA21/50`、最近有效摆动低点或 `2–4 ATR` 的移动保护（这是**适配方案，不是Martin已确认的统一止盈线**）。
- 一次盘中跌破、日线收盘跌破、连续两日跌破，**是三种不同信号**，不能在回测或日报中混用。

### 7.3 推荐的分层止盈状态机【A，须回测】

| 状态 | 条件示例 | 操作 |
|---|---|---|
| `RUNNING` | 价格持续高于上行EMA9、成交量健康 | 主体仓继续持有，逐日更新跟踪参考线 |
| `EXTENDED` | 累计扩张已接近/超过约3×ADR且上涨加速 | 如涨幅/走势支撑，**研究**首批减约10%；其余继续跟踪 |
| `WARNING` | 首次收盘跌破EMA9、量价背离或相对强度转弱 | 做二次确认；短线仓考虑减，核心仓先评估 |
| `TREND_BREAK` | EMA9跌破EMA21、股价失守重要结构且反弹失败 | 分层退出交易仓；核心仓同时对照基本面 |
| `INVALIDATED` | 关键结构/重大业务逻辑失效 | 退出或大幅降风险，而不是继续按亏损比例摊平 |

**特别警惕：** “固定+20%就清仓”会错过50%–200%的主升段；但“永不止盈”又会把利润吐回去。部分锁利 + 趋势跟踪才能兼顾两者。不要把**账面历史最高浮盈**自动当作可实际交易获得的利润。

### 7.4 重要的成功与失败教训【M1】【M2】

- SMCI：Martin说明曾上移止损、参考当时半导体主题和强劲周线，而不是短暂回撤就出局。【M2】
- SOUN：Martin反思没有严格遵守9EMA跟踪止盈，因而付出代价。【M1】
- 若趋势还很强，“减一点仓”和“把仓位清零”差别巨大；每个操作应记录**触发条件**及**实际执行原因**。

## 8. 第七层：做空/弱势反弹失败（研究版，不默认开通）【M3】

> 该部分是 Martin 在2026年发表的一份本人研究，比网络流传“随便跌破21EMA就做空”详细得多；你的主账户如没有做空授权或不希望扩大风险，仅用于判断**减仓/避免抄底**即可。

### 空头形态

1. 高级别趋势向下，尤其价格反弹到**下降中的21/50EMA**附近，多个下降EMA趋于收敛。
2. 若下降的AVWAP（锚在重要高点）也处于同一阻力区，则共振更值得关注。
3. 下切到1小时、5分钟图寻找真正的反转确认：**跌破上一小时K线低点**，或**反弹触碰盘中VWAP/HOD AVWAP后失败**。
4. 原文提及的止损位置：当天高点（HOD）/跌破K高点；常见止损幅度约1.5%–5%；账户风险约0.5%，短空仓位通常不超过35%。
5. 空头只偏向快速波段，而不是长期持有：浮盈超过约3R减约15%；反弹潜在支撑如旧低点/EMA/AVWAP处再减约15%；如果1小时K线收回50EMA上方或股价显著过度延伸，则评估退出。

**不能反推到多头：** 上述“>3R减15%”是他在**短空**研究中给出的经验，不代表全部多头交易都必须到3R就减15%。

## 9. 第八层：核心仓与主动交易仓，必须不同处理【A】

| 维度 | Martin风格主动交易仓 | 你已有的核心/中期仓 |
|---|---|---|
| 建仓 | 新的强势/回调确认 | 基本面、估值、行业轮动和仓位机会成本 |
| 初始止损 | 精确结构位；小风险反复试错 | 不能用事后设定的1%止损重写旧买单 |
| 止盈 | 部分约10%，试验9/23EMA趋势跟踪 | 重点防利润回吐，宽松EMA/ATR/周线及事件结合 |
| 加仓 | 首次回踩、再突破后新信号 | 需先检查现有仓位、相关敞口和剩余现金 |
| 异常风险 | 流动性、跳空、过度交易 | 税务、长期逻辑变化、账户集中度、卖出Covered Call占用 |

### 已有仓位分析规则【A】

- **三层结论并列呈现**：①原有基本面/估值结论；②Martin风格趋势结论；③全账户仓位风险结论。
- 输出状态：`ADD_CANDIDATE / HOLD_TREND / PROTECT_PROFIT / REDUCE_TRADE_SLICE / WAIT / EXIT_REVIEW`。
- **若技术建议减，但基本面和核心配置依然支持持有**：优先研究减**交易仓那一部分**，而不是默认整只股票清仓；如果重大风险/事实变化则另外处置。
- VST、IREN、BE、NBIS、MU、MRVL等只能按**最新持仓、已完成K线和实时确认**给买卖意见。本文不给2026-10-15以后的实时触发价格，不冒充实时建议。
- 卖出正股前核查Covered Call：若100股被1张仍未平仓空头Call覆盖，直接卖掉该100股可能形成无法许可的裸Call，必须先处理期权或保留足额担保。

### 日内/盘前时间一致性

- 纽约开盘9:30时，**当天日K未完成**；任何使用“当天收盘价>EMA9”的规则不能被宣称已确认。

## 11. 第十层：日报模块建议（对原有报告**只增加，不替换**）【A】

每次输出下表，涵盖**最新真实主账户全部股票**：

| 字段 | 含义 |
|---|---|
| `symbol / shares / avg_cost` | 真实持仓、最新股数和成本，来源与时间戳 |
| `last_price / price_asof` | 最新价及行情时间，不混用盘后与收盘 |
| `ema9/ema21/ema23/ema50` | 价位、均线方向、股价相对偏离 |
| `atr14 / adr20 / volume_ratio20` | 波动、量价结构 |
| `leader_state` | `LEAD / MEDIOCRE / LAG / TRANSITION` |
| `setup` | `BREAKOUT / FIRST_PULLBACK / NO_SETUP` |
| `signal_state` | `WATCH / PRE_TRIGGER / CONFIRMED / INVALIDATED` |
| `martin_style_action` | `候选加仓/持有趋势/先减交易仓/止盈保护/等待` |
| `entry_or_add_trigger` | 入场和加仓的**条件**，不是无条件价格 |
| `partial_take_profit_trigger` | 约3×ADR扩张/加速/放量滞涨等提示 |
| `initial_stop_or_structure_invalidation` | 对新仓用初始止损；对旧核心仓为结构失效参考 |
| `size_budget / capital_needed` | 按账户总风险和已持仓计算，未确认则不填 |
| `options_constraints / thesis_conflict` | Covered Call占用、原基本面结论冲突 |

日报结论必须明确分组：

1. **真正符合 Martin 风格的加仓候选**（可以为零）；
2. **盈利回吐预警与需要减交易仓的股票**；
3. **虽跌破均线但不宜仅凭均线卖出的核心仓**；
4. **全市场新的Leader候选**——不因为用户旧名单优先于其他行业；
5. **今天不交易的条件与理由**。

这层的作用是提供可反驳、可执行的技术第二意见，**原报告的基本面、行业判断、止盈体系、期权/covered call和风控继续独立运行**。

## 12. 第十一层：必要的回测与验证

### 回测对照组

- 基线A：不增加本策略，仅使用现有账户买入持有/原计划管理。
- 基线B：固定10%、20%、30%比例止盈。
- 策略C：首批约10%减仓 + 9 EMA跟踪。
- 策略D：首批约10%减仓 + 23 EMA跟踪。
- 策略E：强势股首次回踩入场 + 基于结构的紧止损 + 9/23 EMA移动止盈。
- 策略F：对核心仓采用更宽松的21/50EMA或ATR追踪，避免错杀。

### 衡量指标

- 净收益、最大回撤、回撤持续时间、Calmar、每笔实际盈亏比与R分布；
- 止损率、重入次数、连续亏损峰值、胜率、交易频率、实际滑点；
- **从浮盈峰值回吐的比例**及本应保留的利润；
- 错失上涨：若过早减仓后股票继续翻倍，须计入机会成本；
- 交易成本、税务情景、仓位集中度与主题相关性。

### 防止漂亮但无效的回测

- 至少跨牛市、震荡、急跌、财报季等多个市场状态；包含已退市股票，避免幸存者偏差。
- 时间点严格：信号基于当时已知数据，开盘/收盘确认和成交的时间先后一致。
- 使用训练/验证/未来样本区分，不对某几只大牛股过度优化9/21/23等参数。
- 计入跳空、停牌、宽买卖价差、分批卖出对实际可成交价格的影响。
- 小样本/参数敏感时，**只输出“研究中/不建议实盘上线”**；不编造胜率。
