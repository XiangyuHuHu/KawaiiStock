# 纸上实验的交易时段

八本账都只改自己的纸上账。`liveTrading` 保持 false，没有券商下单。

每本账用自己的市场时钟：

| 账本 | 市场 | 何时跑 |
| --- | --- | --- |
| 0A–0F、0H | 美股 | 美东 9:30–16:00，交易日 |
| 0G | A 股 | 北京时间 9:30–11:30、13:00–15:00，交易日 |

午休、周末、休市日不跑。美股休市表在 `src/paths.js` 的 `US_MARKET_CLOSED`。A 股 2025–2026 按交易所安排，2027–2028 只盖住元旦、春节、清明、劳动节和国庆，调休补班没有逐日打开。

每日任务只在它被叫醒的那一刻，跑当时开着的市场。A 股上午美股还关着，所以只靠每日任务的话，0G 仍然不下单。盘中要靠下面的守护进程。

## 怎么跑

一次性，只跑此刻开着的账本：

```bash
npm run paper -- --auto
```

常驻。开市期间默认每 20 分钟一轮，两个市场都关着就睡到下一次开市。适合一台一直开着的 Linux：

```bash
npm run paper:daemon
npm run paper:daemon -- --interval 15
npm run paper:daemon -- --once
```

`--interval` 限制在 5–60 分钟。环境变量 `PAPER_DAEMON_INTERVAL_MIN` 同样生效。`--once` 给 cron 用，跑完就退出。

systemd 示例：

```ini
[Service]
WorkingDirectory=/opt/kawaii
ExecStart=/usr/bin/npm run paper:daemon -- --interval 20
Restart=on-failure
```

`--force` 只忽略 `desk-config.json` 里的 `paper.autoAtOpen=false`，不绕过交易时段。

每一轮写两份东西：

- `reports/YYYY-MM-DD-纸上实验.jsonl`：每次一行
- `reports/YYYY-MM-DD-纸上实验.md`：这一天最近一轮的表

表里有扫描数、买点数、成交和拒绝原因。每日任务 JSON 的 `paper.auto.sessions.*.diagnostics` 里也有同样的摘要。纸上页会显示最近一次诊断。

## 0G 宇宙

不读自选里的 600519、300750、000001。那三只流通市值不在 50–200 亿，也凑不齐同名单 3 只涨停。

可复现的底是 `lists/cn/小孟中小盘.md`。2026-10-19 用东财流通市值 `f21` 筛过，大约落在 54–186 亿，分成 AI算力、软件、半导体、机器人、新能源、军工。运行时再用行情市值滤一次。

东财涨停池接口不接受历史日期，返回的总是当天。进程会把市值带内、且不是 ST 的涨停按行业写到 `data/paper/zt-pool/YYYY-MM-DD.json`。接下来几个交易日把这些快照并进宇宙，这样昨天的涨停才能参加板块共振。第一天没有快照时，只靠静态名单。

## 0H 阈值

美股没有涨停。旧规则把 50–200 亿人民币除以 7.2，得到大约 $0.69B–$2.78B，再要求当天至少 +8% 且收在高点 0.3% 以内，并且同一名单至少 3 只、前一日中位数至少 +3%。主题名单上这几条很少同时成立。

现在的 `us-v2`：

| 条件 | 旧 | 新 | 原因 |
| --- | --- | --- | --- |
| 大涨 | +8%，收在高点 0.3% 内 | +5%，收在高点 0.5% 内 | 5% 大约是两倍日波动，一个月里见得到；8% 更像偶发 |
| 市值 | 约 $0.69B–$2.78B | $0.5B–$20B 总市值 | 原上限把名单上的中型股挡掉，20B 仍不包括超大盘。Nasdaq 只给总市值 |
| 共振 | 至少 3 只，中位数 ≥ 3% | 至少 2 只，中位数 ≥ 1% | 美股名单比 A 股涨停潮稀疏 |
| 盘口 / 集合竞价 / 封单 | 没有数据源。旧代码没有把它写成否决，注释容易看成失败 | 缺失记为中性，不否决 | 没有 Level-2，不能用缺失来挡成交 |

A 股规则不变：涨停、50–200 亿、至少 3 只、中位数 ≥ 3%。

清单缺失或不足 8 个代码时，0H 用 `lists/us/小孟美股.md`，避免退回那 10 只 public-demo 超大盘。清单还在就继续扫清单。

对照回测（只读行情，不下单）：

```bash
npm run paper:xiaomeng-backtest
```

它用上面的美股备用名单，从 2026-07-01 起数 `us-v1`、把盘口缺失当成否决的对照、以及 `us-v2` 各会出多少次信号。市值用 Nasdaq summary 的总市值（`MarketCap`），不是流通市值，也不是历史时点市值：整段回测共用运行当天的市值。Yahoo chart 的 `meta.marketCap` 已经空了，不能再当过滤依据。
